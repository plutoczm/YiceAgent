# V2-4 上下文与记忆验收

日期：2026-10-05。范围：第四阶段；第五阶段综合展示与整体验收尚未开始。

## 实现

- 独立workflowops_agent PostgreSQL schema保存会话、原始消息、run、摘要版本、上下文快照、私有工具结果、记忆候选、确认记忆及幂等回执。
- LangGraph由真实封闭意图驱动必需读取和订单动作草案；商品/工单参数可使用原生工具调用或结构化模型计划。记录协议来源，不将结构化计划冒充原生调用。
- 确认/审批/模拟履约复用业务服务，模型无权执行。等待确认结束run，后续界面确认形成关联run。
- 同会话一个活动turn；客户端请求ID重复返回已有run；模型切换只在完整turn边界。
- 窗口4096/8192/16384。默认8192，输出预留1536、安全512、输入6144。cl100k_base是跨供应商估算，usage参与校准，不声称原生精确计数。
- 每次模型调用前检查预算，包含摘要、意图复核和工具返回之后的请求。75%触发整理，约55%为目标；保留最近4个完整轮次、当前请求、纠正、业务引用和确认状态，容量不足明确停止。
- 工具调用和结果成组处理；旧结果改为可读引用，原始历史不因裁剪删除。摘要仅接受连续原文，核对保护约束、数字及ID，分批请求也受预算限制，全部校验后提交版本。
- 候选确认后生效；修改保留版本；删除/过期/归属和旧向量版本由PG权威过滤。模型上下文排除旧记忆版本；回忆由模型选择来源ID、应用读取原文，并在发布时再次核对记忆版本。
- 知识与记忆使用独立Qdrant collection，真实BGE-M3 embedding。本项目Qwen请求和BGE任务结束后释放驻留资源，在8GB显存下串行执行。
- 6次模型/8次工具/一次参数修复/10分钟截止。重复参数及版本、调用环、连续无新增信息等确定性停止。摘要与复核计入上限。

## 失败与限制

早期schema、Qwen意图/引用、摘要过大、CPU/JSONL断开、窗口不足、草案参数失败均保留。run结束不等于语义通过，早期只有运行结束的试跑不能替代门禁。

Qwen复杂历史中可能把回忆归为知识问题，或把草案归为查询/下单。现采用同通道封闭类别复核和确定性业务流程；复核不能修改权限或证明事实。模型失败时明确停止，没有换模型替代失败。

30轮结果只覆盖冻结输入与指定事实，不是任意对话质量保证。假模型测试证明控制器边界，真实模型结果分别记录。循环、参数修复、窗口不足、取消、过期、越权、记忆竞态与幂等经过实际PG测试。
