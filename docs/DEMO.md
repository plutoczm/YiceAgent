# 工作台演示

全部订单、商品、规则及支付退款结果均为本机模拟数据。当前五个视图共用一个演示身份；两个租户各有客户和运营，权限由服务端决定。

## 启动

在项目根目录双击 start.cmd，或运行：

```powershell
& ".\.runtime\v2\envs\main\Scripts\python.exe" -B scripts/manage.py up
```

浏览器打开 http://127.0.0.1:8020。Docker Desktop 和 Ollama 须先运行，项目专用 PostgreSQL/Qdrant 容器须已启动。启动不安装依赖、不重置数据库。重启应用后需重新选择演示身份，历史会话、摘要和已确认记忆仍在。

停止使用 stop.cmd；仅停止项目 HTTP，保留数据库、模型和结果。

## 十分钟演示

1. 选择客户 A1，在 智能助手选择 ChatGPT、DeepSeek 或 Qwen，新建会话。问“电商已发货后还能取消吗？请引用演示规则”。展示逐字证据、来源和版本。
2. 发送“请记住：本次演示偏好中文简短回答，学习代号是DEMO-A17；不要自动支付”。去知识与记忆确认候选。新会话询问已确认偏好，展示跨会话召回。
3. 返回原会话，发送“纠正：偏好改为英文详细回答，学习代号改为DEMO-B29”。旧候选失效；修改已确认记忆以保持长期值一致。两种操作分别显示版本与来源。
4. 进行较长对话或用固定30轮验收入口触发自动压缩。也可点击手动整理上下文。去上下文查看调用快照、75%触发/55%目标、输入预算、入选/省略理由、摘要版本和原消息引用。短会话没有较早轮次时不会强行创建摘要。
5. 在完整轮次之间切换模型和4096/8192/16384应用窗口，保存后再提问。窗口是应用预算；每次调用重新组装规范消息，模型原生窗口另受适配器校验。
6. 发送“下单电商商品ECO-A-CABLE，数量1，备注面试演示，只生成草案”。核对19.90元报价并在动作区确认。模型参数经业务服务校验，确认前没有新订单。
7. 为刚创建的订单生成支付草案并确认。切换运营 A，到订单管理执行模拟支付成功及配送推进。电商路径为待支付→已支付→待发货→已发货→已送达；外卖依次已接单→制作中→配送中→已送达。
8. 切回客户 A1，申请整单退款草案并确认；运营模拟退款结果。只有结构化业务字段显示模拟已退金额。外卖可用FOOD-A-TEA重复演示。
9. 高额取消使用ECO-A-PHONE（899元）或FOOD-A-FAMILY（129元）。已支付取消先运营审批再客户确认，随后运营模拟退款；电商发货后/外卖接单后直接取消被拒绝，可生成异常工单草案。
10. 打开运行中心，展示意图、模型调用、工具结果、校验、usage和停止原因。刷新页面恢复所属会话的最新运行；换客户 A2/B1验证原会话不显示。

## 知识库与模型

在知识与记忆查看文档版本、来源、许可和哈希。运营可导入内置中文演示资料；同版本索引复用，改变模型或切分策略需另建索引。界面不接收任意URL、服务器文件路径或租户参数。

DeepSeek项目专用Key仅在隐藏输入入口保存，累计DeepSeek/Jev上限15元；调用前最高成本预留，未知usage按预留记账。ChatGPT使用项目OAuth，订阅usage单列。登录失效、模型不可用或额度不足会明确失败；账号登录由用户操作。不要把凭据发到聊天或文档。

## 固定验收

```powershell
& ".\.runtime\v2\envs\main\Scripts\python.exe" -B scripts/manage.py verify
& ".\.runtime\v2\envs\main\Scripts\python.exe" -B scripts/validation/verify.py evidence
```

前者跑离线控制器及真实本地数据库回归，自动阻止普通测试调用模型。后者核对本机冻结证据的哈希，缺文件或源码变化会失败。

真实验收需要已有授权、可用账号和可靠费率配置；会消耗订阅额度/DeepSeek费用：

```powershell
& ".\.runtime\v2\envs\main\Scripts\python.exe" -B scripts/validation/verify.py live --approved
```

这会顺序执行三通道双业务、对抗资料、每通道30轮及真实记忆/模型切换。业务脚本用本轮UUID测试schema并清理它；不重置public或v1数据。浏览器验收需要按上述步骤实际操作，不能由截图或CLI替代。

主库的确定性可重放剧本仍为 scripts/manage.py replay-demo --approved，每次新增4个演示订单并保留结果。

## 故障展示

不存在或无权访问的订单返回无法核实。政策无证据/冲突明确拒答；伪造引用无法发布。大结果转成可读引用或分页；关键约束仍放不下时提示拆分输入或增大窗口。可以在运行中取消，查看持久化状态。

工具执行结果未知时按动作ID核对，禁止自动重放。循环、重复、无新增信息、参数修复、模型/工具次数及10分钟截止均有确定性门禁。

已验证范围和失败局限见 validation/workbench.md；Jev仍为可选实验NOT_RUN。
