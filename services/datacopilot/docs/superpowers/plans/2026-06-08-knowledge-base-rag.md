# 知识库 RAG 实施计划（历史记录）

> 本计划已完成，仅用于追溯早期设计过程。

## 目标

实现从文档加载、结构切分、Embedding、向量存储、检索到引用回答的完整 RAG 流程。

### 任务 1：RAG 契约测试

- 验证 TXT、Markdown、PDF 和 DOCX 加载。
- 验证递归切分、分块重叠和文本清理。
- 验证 Top K、元数据过滤、分数阈值和引用。

### 任务 2：应用服务

- 实现文档摄取、切分、检索、引用和 RAG 回答服务。
- Grounded Prompt 只允许使用召回上下文。
- 无召回时返回明确拒答，不调用大模型编造内容。

### 任务 3：基础设施

- 实现文件类型对应的文档加载器。
- 实现 BGE-M3 Embedding Provider 和缓存。
- 通过 `VectorStore` 端口写入 ChromaDB。

### 验证

- 运行 RAG 单元和集成测试。
- 检查回答引用、Token 统计和持久化结果。
