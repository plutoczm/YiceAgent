# DeepSeek Provider 实施计划（历史记录）

> 本计划已完成，仅用于追溯早期设计过程。

## 目标

通过统一大模型端口接入 DeepSeek，支持普通对话、流式输出、健康检查和错误治理。

### 任务 1：Provider 契约测试

- 验证请求模型、消息、温度和最大 Token 参数。
- 验证普通响应、SSE 分片和 Token 使用量解析。
- 验证认证、限流、超时、连接错误和无效响应。

### 任务 2：领域端口

- 定义 `LLMMessage`、`LLMResponse`、`LLMUsage` 和健康状态。
- 定义与具体厂商无关的 `LLMProvider` 协议。

### 任务 3：DeepSeek 适配器

- 使用异步 httpx 客户端。
- 实现有限重试、指数退避、超时和异常映射。
- 密钥从配置读取，不写入日志和响应。

### 验证

- 使用 MockTransport 完成离线测试。
- 运行全量测试并检查日志中没有密钥。
