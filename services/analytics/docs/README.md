## 推荐阅读顺序

1. 根目录 `README.md` 和 `START.md`。
2. `AGENT_TECH_STACK.md` 了解完整技术链路。
3. `ARCHITECTURE.md` 理解代码边界和数据流。
4. `API_REFERENCE.md` 与 `DEPLOYMENT.md` 完成调用和部署。
5. `INTERVIEW_GUIDE.md` 准备项目演示与面试说明。
