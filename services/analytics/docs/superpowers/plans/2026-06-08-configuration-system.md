# 配置系统实施计划（历史记录）

> 本计划已完成，仅用于追溯早期设计过程。

## 目标

使用 Pydantic Settings 建立类型安全、可分环境覆盖且不会泄露密钥的配置系统。

### 任务 1：配置契约测试

- 验证开发、测试和生产环境枚举。
- 验证相对路径解析到项目目录内。
- 验证 CPU/GPU 互斥和生产环境安全设置。
- 验证环境变量嵌套覆盖与敏感字段隐藏。

### 任务 2：核心实现

- 定义应用、路径、日志、大模型、Embedding 和运行时配置模型。
- 支持 `.env.example`、`.env` 和系统环境变量。
- 对路径、端口、超时、重试次数和日志级别设置校验。

### 验证

- 运行配置单元测试和全量测试。
- 检查 OpenAPI 不暴露 SecretStr。
- 确认所有运行目录位于项目根目录内。
